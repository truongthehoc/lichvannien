# Lịch Vạn Niên Đại Việt 🇻🇳

Ứng dụng tra cứu Lịch Âm Dương, Lịch Pháp Hoàng Đạo, Tử Vi, Thần Số Học, Phong Thủy truyền thống Việt Nam dựa trên giải thuật thiên văn độ chính xác cao của nhà nghiên cứu Hồ Ngọc Đức (múi giờ GMT+7 Việt Nam).

## ✨ Tính Năng Nổi Bật

- 📅 **Lịch Vạn Niên & Tờ Lịch Ngày Chi Tiết**: Tra cứu âm dương, can chi ngày/tháng/năm, tiết khí, giờ hoàng đạo/hắc đạo.
- 🔮 **Tử Vi Hàng Ngày & Vận Mệnh**: Dự đoán vận số 12 con giáp mỗi ngày, cát hung theo tuổi.
- 🔄 **Đổi Ngày Âm Dương**: Chuyển đổi 2 chiều chuẩn xác, đếm ngược ngày Tết Cổ Truyền.
- ⭐ **Xem Ngày Hoàng Đạo & Thần Sát**: Tra cứu ngày tốt xấu, trực, sao cát tinh, bách kỵ cưới hỏi, xuất hành, khai trương.
- 📜 **Lá Số Tử Vi Trọn Đời**: Lập lá số 12 cung bản mệnh, thân, tam hợp, tứ hóa.
- 🌟 **Tra Cứu Sao Hạn & Tam Tai**: Cửu Diệu niên hạn, Tam Tai, Kim Lâu, Hoang Ốc kèm văn khấn cúng sao giải hạn.
- 🔢 **Thần Số Học Pitago**: Phân tích con số chủ đạo cá nhân, giải mã Crush & tương hợp cặp đôi.
- 🪙 **Gieo Quẻ Kinh Dịch**: Bói dịch 3 đồng xu 64 quẻ chuẩn truyền thống.
- 📏 **Thước Lỗ Ban Phong Thủy**: Đầy đủ 3 loại thước 52.2cm (Thông thủy), 42.9cm (Dương trạch), 38.8cm (Âm phần).
- 🛠️ **Trang Quản Trị Hệ Thống (`/admin`)**: Quản lý thương hiệu, logo, cấu hình thông báo đầu trang (thời gian, độ trễ, thời lượng, hiệu ứng động), tài khoản quyên góp VietQR tự động, quản lý tính năng.

## 🚀 Công Nghệ Sử Dụng

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/), Lucide Icons
- **Ngôn ngữ**: TypeScript / React 19
- **Thuật toán thiên văn**: Giải thuật âm lịch Việt Nam (Hồ Ngọc Đức)

## 📦 Cài Đặt & Chạy Cục Bộ

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển
npm run dev

# Mở trình duyệt tại http://localhost:3000
```
